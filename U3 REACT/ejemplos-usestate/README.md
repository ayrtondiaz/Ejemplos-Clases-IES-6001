# Ejemplos de useState - React

Aplicación Vite + React con 3 ejemplos progresivos del hook `useState`.

## Ejemplos incluidos

1. **Contador Interactivo** — useState con números, setter, re-render
2. **Formulario Controlado** — useState con strings, inputs controlados, preview en vivo
3. **Lista de Tareas** — useState con arrays de objetos, inmutabilidad (spread, map, filter)

## Instrucciones

```bash
npm install
npm run dev
```

Abrir http://localhost:5173 en el navegador.
